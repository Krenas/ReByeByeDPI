# Авторство и благодарности

Этот репозиторий является производным проектом на основе ByeByeDPI Android. Сведения ниже составлены по файлу README оригинального проекта и объявлениям используемых зависимостей. Это список явно указанных upstream-авторов и проектов, а не заявление о том, что он исчерпывает всех участников.

## Основное Android-приложение

- **romanvht** — автор оригинального проекта ByeByeDPI Android.  
  Репозиторий: https://github.com/romanvht/ByeByeDPI

- **dovecoteescapee** — автор первоначальной реализации ByeDPIAndroid, на которую ссылается README оригинального проекта.  
  Репозиторий: https://github.com/dovecoteescapee/ByeDPIAndroid

## Используемые компоненты

- **hufrea** — автор ByeDPI, нативной сетевой библиотеки, используемой проектом.  
  Репозиторий: https://github.com/hufrea/byedpi

- **heiher** — автор hev-socks5-tunnel, используемого проектом.  
  Репозиторий: https://github.com/heiher/hev-socks5-tunnel

## Производный проект

- **Krenas/ReByeByeDPI** — пользовательский форк для разработки и сопровождения производной версии.  
  Репозиторий: https://github.com/Krenas/ReByeByeDPI
